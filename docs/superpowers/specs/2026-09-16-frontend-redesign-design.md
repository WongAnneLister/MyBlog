# 个人博客前端视觉与交互重构设计规范

## 1. 目标与背景

当前博客在视觉呈现与排版体验上存在以下核心痛点：
1. **中英文排版生硬冲突**：强行指定了英文衬线字体 `Georgia`，导致中文标题被操作系统回退到粗重黑体或锯齿宋体，字重与行高不协调；
2. **卡片拉伸与空间浪费**：在宽屏（>1050px）下，文章被硬拉到 1080px 宽度的单列，不仅显得过于空旷扁平，且置顶文章与普通文章缺乏视觉层级；
3. **色彩对比单调刺眼**：全黑纯底（`#101111`）与刺眼荧光绿（`#9bf443`）搭配生硬，缺少现代高阶开发者界面的微光（Ambient Glow）通透感与层次；
4. **左侧栏结构臃肿**：采用“深色侧栏套深色方框”的双层外框，垂直信息割裂且底部有大面积空白。

本次重构旨在确立**「Linear 极客微光暗黑风」**结合**「精修人文宋体（Noto Serif SC + Newsreader）」**的设计语言，将博客打造为兼具专业技术质感与深度阅读呼吸感的个人数字花园。

## 2. 设计规范与 Design Tokens

### 2.1 色彩与微光系统 (Color & Glow Tokens)
- **主背景色 (`--bg`)**：`#090a0f`（深邃微蓝夜空黑，带有极弱的环境漫反射）
- **侧边栏背景 (`--side`)**：`#0d0f15`
- **卡片基底色 (`--card`)**：`#12151e`（半透明层叠微光卡片）
- **主强调色 (`--accent`)**：`#10b981`（祖母绿微光 Emerald）
- **发光描边色 (`--line`)**：`rgba(255, 255, 255, 0.08)`（极细微光边界，替代纯色粗边框）
- **次级分隔线 (`--dash`)**：`rgba(255, 255, 255, 0.05)`
- **主要文本色 (`--text`)**：`#f1f5f9`（温润高对比白，避免刺眼纯白）
- **次级次要文本 (`--muted`)**：`#828a9b`（清晰易读的冷灰）
- **微光阴影 (`--glow-shadow`)**：`0 0 24px rgba(16, 185, 129, 0.12)`

### 2.2 字体排版系统 (Typography)
- **中文正文与标题字体**：
  ```css
  --font-serif: 'Noto Serif SC', 'Source Han Serif SC', Songti SC, serif;
  ```
- **英文标题与强调字体**：
  ```css
  --font-editorial: 'Newsreader', Georgia, serif;
  ```
- **代码、时间与元数据字体**：
  ```css
  --font-mono: 'JetBrains Mono', 'DM Mono', ui-monospace, monospace;
  ```
- **UI 与标签后备字体**：
  ```css
  --font-sans: -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Hiragino Sans GB", sans-serif;
  ```
- **排版微调**：
  - 中文大标题：`font-weight: 600`，`line-height: 1.4`，微收字距 `-0.015em`；
  - 正文排版：`line-height: 1.75`，段落间距 `1.25rem`；
  - 英文大标题：选用优雅的 Newsreader 变体。

## 3. 架构与组件设计

### 3.1 左侧边栏重构 (Profile Sidebar)
- **一体化无框设计**：消除 `.profile-card` 的外层黑框嵌套，侧边栏作为平滑整体呈现，顶部融入极淡的祖母绿径向渐变微光。
- **头像展示**：
  - 82px 居中圆形头像，配备双层柔光外圈（`box-shadow: 0 0 0 2px rgba(255,255,255,0.08), 0 8px 24px rgba(0,0,0,0.5)`）；
  - 右下角新增呼吸感在线状态指示点（`#10b981` 脉冲光）。
- **博主名与身份标签**：
  - 姓名使用 `Newsreader` 渲染，字重 600；账号使用等宽小字 `@MichikatsuOwO`；
  - 融入紧凑微胶囊标签：`⚽ Football × 💻 Software × 🤖 AI`，展示跨界特色；
  - 简洁横向统计行：`8 篇思考 · 3 个作品`。
- **胶囊导航（Pill Navigation）**：
  - 导航按钮从生硬的点符号升级为微圆角胶囊块（Home / About / Projects / Blog）；
  - 激活态（Active）高亮背景（`rgba(16, 185, 129, 0.1)`）并伴随右侧微光绿色小圆点指示，Hover 态平滑浮亮。
- **底部辅助功能**：
  - 极简版权年份与设置快捷面板唤起按钮。

### 3.2 主内容区 Feed 流与卡片架构 (Main Feed Layout)
- **置顶精选 Hero 卡片**：
  - 置顶文章独占 **全宽通栏**；
  - 渐变微光底色（深青到暗夜黑）与 `★ 置顶精选` 祖母绿徽章；
  - 突出文章发布时间、阅读时长预估、核心摘要与分类标签，右下角配以动态伸缩的阅读箭头。
- **普通文章双列卡片流 (Dual-Column Bento Grid)**：
  - 非置顶文章在桌面端（宽屏）自动转为 **2 列 Grid 布局**（`grid-template-columns: repeat(2, 1fr)`）；
  - 彻底解决单列横拉导致的视觉空洞，形成高宽比舒适的阅读卡片；
  - 卡片鼠标悬停响应：微上浮 3px（`translateY(-3px)`）+ 翡翠边框微光扩散。
- **文章详情与阅读视图优化 (Reader View)**：
  - 进入文章正文页后，限制阅读视宽为黄金比例 `780px`（居中排版），避免视线在大屏来回大幅扫视；
  - Markdown 代码块增加暗黑半透明深色磨砂背景、圆角及高亮色彩。
- **项目作品卡片 (Projects Grid)**：
  - 项目保持双列展示，优化封面图圆角遮罩与 Hover 缩放微动效；
  - 项目标签（Tags）优化为半透明微代码胶囊。

## 4. 响应式与跨端适配 (Responsive Strategy)

| 视口尺寸 | 布局策略 |
| :--- | :--- |
| **桌面宽屏 (> 1050px)** | 固定左侧名片栏（280px） + 主内容区（最大 1080px），文章呈置顶通栏 + 普通双列网格。 |
| **平板中屏 (768px - 1050px)** | 左侧栏紧凑收纳，内容区自适应伸缩，文章卡片根据可用宽度弹性排列。 |
| **移动端 (< 768px)** | 侧边栏转换为顶部优雅折叠/抽屉栏，卡片自动转为单列全宽自适应，保留微光与精致排版。 |
